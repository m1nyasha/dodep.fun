# Архитектура

```
Браузер ──HTTPS──▶ Traefik (Dokploy)
                     ├─ dodep.fun            ─▶ app   (Nuxt SSR, :4100) ──▶ api по внутренней сети (SSR)
                     ├─ dodep.fun/api        ─▶ api   (NestJS, :4200)
                     ├─ admin.dodep.fun      ─▶ admin (nginx + SPA, :80)
                     └─ admin.dodep.fun/api  ─▶ api   (тот же контейнер)
                                                  │
                                                  ▼
                                    MySQL 8.4 (Timeweb Cloud)
```

Браузер всегда ходит в API по относительному `/api` того же домена: нет CORS, cookie первой стороны. Nuxt на сервере ходит в API напрямую по `NUXT_API_INTERNAL_URL`, пробрасывая cookie запроса.

## Пакеты

| Пакет    | Что внутри                                                                                         |
| -------- | -------------------------------------------------------------------------------------------------- |
| `shared` | математика игры (шансы, множители, выплата), расписание ежедневной выдачи, `layoutString`, DTO API |
| `api`    | NestJS: auth, игра, игроки, лента, admin API, Drizzle-схема и миграции                             |
| `ui`     | Nuxt layer: токены, базовые `Ui*`-компоненты, общие composables                                    |
| `app`    | публичный сайт                                                                                     |
| `admin`  | админка (SPA)                                                                                      |

## Источник истины

Баланс, раскладка мин, исходы и выплаты считаются только в API, в транзакциях MySQL с `SELECT … FOR UPDATE` (порядок: пользователь, потом раунд). Фронт использует `shared` только для отображения лестницы множителей. История: `rounds` + `round_actions` + `ledger`; `users.total_*` — денормализованные суммы для рейтинга.

## Потоки

**Игра.** `POST /api/rounds` списывает ставку и возвращает `hash = sha256("<мины>:<соль>")`. `open` открывает клетку; мина или 20-я безопасная клетка завершают раунд. `cash-out` выплачивает `round(ставка × множитель)`. После завершения клиент получает мины и соль и может сверить хэш.

**Авторизация.** Ник и пароль (argon2id). Сессия — случайный токен в httpOnly-cookie `sid` на 30 дней, в БД — его sha256. Каждый вход и регистрация пишут отпечаток (`auth_fingerprints`), регистрация ограничена числом попыток с IP за окно из `settings`.

**Админка.** Админ на основном сайте видит кнопку → `POST /api/me/admin-ticket` выдаёт одноразовый тикет на 60 с → переход на `admin.dodep.fun/auth?ticket=…` → `POST /api/admin/auth/exchange` ставит host-only cookie `admin_sid` на поддомене. Публичная `sid` админ-API не открывает. Swagger: публичный `/api/docs`, админский `/api/admin/docs` — только с `admin_sid`.

**Живая лента.** API рассылает `round.finished` всем подключённым к `wss://<домен>/api/ws`. Рассылка из памяти процесса — API работает в одном экземпляре.

**Ошибки.** api, app и admin отправляют ошибки в self-hosted Bugsink (Sentry-протокол), если задан DSN. 4xx предметной области не отправляются.
